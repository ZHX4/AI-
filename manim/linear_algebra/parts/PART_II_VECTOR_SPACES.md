# Part II — Vector Spaces

Part II builds the abstract language behind linear algebra while keeping the geometry visible. The core question changes from "what does this vector look like?" to "what entire collection of vectors can be generated, represented, or lost?"

## Lessons

1. **Span** — reachable vectors and the set generated by linear combinations.
2. **Linear Dependence** — redundancy and combinations that cancel to zero.
3. **Linear Independence** — genuinely different directions of information.
4. **Basis** — spanning plus independence, and unique coordinates.
5. **Dimension** — counting independent directions rather than points.
6. **Nonstandard Coordinates** — why the same vector can have different coordinate descriptions.
7. **Subspaces** — smaller spaces closed under addition and scalar multiplication.
8. **Column Space** — all outputs a matrix can produce.
9. **Row Space and Null Space** — independent row information and inputs sent to zero.
10. **Rank and Nullity** — surviving versus lost input dimensions.
11. **Four Fundamental Subspaces** — column space, row space, null space, and null space of the transpose.

## Teaching rhythm

Every lesson follows:

**Question → geometry → CC explanation → equation → numerical example → interpretation → connection forward.**

The CC is intended to work as the written narration: it explains what changes on screen and why the change matters. The animations should be understandable even with the audio muted.

## Key ideas developed

- `span(S)` is the set of all linear combinations of vectors in `S`.
- Linear independence means the zero vector has only the trivial representation.
- A basis is both spanning and linearly independent.
- Dimension is the number of vectors in any basis of the space.
- Coordinates depend on the chosen basis.
- A subspace contains the zero vector and is closed under addition and scalar multiplication.
- The column space is the range of the matrix map.
- The null space is the set of inputs sent to zero.
- Rank counts independent output directions.
- Nullity counts independent input directions that are lost.
- `rank(A) + nullity(A) = number of columns of A`.
- The four fundamental subspaces organize the row/column information and their orthogonal complements.
