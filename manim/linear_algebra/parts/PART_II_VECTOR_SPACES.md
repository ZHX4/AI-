# Part II — Vector Spaces

Part II builds the abstract language behind linear algebra while keeping the geometry visible. The core question changes from **what does this vector look like?** to **what whole collection of vectors can be generated, represented, measured, or lost?**

## Lessons

1. **Span** — reachable vectors and the set generated by linear combinations.
2. **Linear Dependence** — redundancy and nontrivial combinations that cancel to zero.
3. **Linear Independence** — genuinely different directions of information.
4. **Basis** — spanning plus independence, with unique coordinates.
5. **Dimension** — counting independent directions rather than points.
6. **Nonstandard Coordinates** — the same vector can have different coordinates in different bases.
7. **Subspaces** — smaller vector spaces closed under addition and scalar multiplication.
8. **Column Space** — all outputs a matrix can produce.
9. **Row Space and Null Space** — measured input directions and directions sent to zero.
10. **Rank and Nullity** — surviving versus lost input dimensions, with rank–nullity.
11. **Four Fundamental Subspaces** — column space, row space, null space, and null space of the transpose, including both orthogonal pairings.

## Teaching rhythm

Every lesson follows:

**Question → geometry → CC explanation → equation → worked example → interpretation → connection forward.**

The CC is written as the lesson's on-screen narration. It explains what changes on screen, why the change occurs, and what mathematical idea the viewer should take away.

## Mathematical checkpoints

- Span is the set of all linear combinations of the generators.
- Dependence means a nontrivial linear combination equals zero.
- Independence means only the trivial combination equals zero.
- A basis is spanning and linearly independent.
- Dimension is the number of vectors in a basis.
- Coordinates depend on the chosen basis.
- A subspace contains the zero vector and is closed under addition and scalar multiplication.
- The column space is the range of the matrix map.
- The null space is the set of inputs mapped to zero.
- Rank counts independent output directions.
- Nullity counts independent input directions lost by the map.
- `rank(A) + nullity(A)` equals the number of columns of `A`.
- `Row(A) ⟂ Null(A)`.
- `Col(A) ⟂ Null(A^T)`.
